Hi, I'm Wren. I write software for a living and build small things on weekends: command
line tools, browser toys, and the occasional circuit that works on the second try.

This site is where I keep notes on those projects. You'll find:

- **[Blog posts](/blog/)** about what I learned, what broke and how I fixed it
- **[Projects](/projects/)**, from [software](/projects/software/) to
  [hardware](/projects/hardware/)
- **[Tags](/tags/)**, if you only care about one topic, like [Rust](/tags/rust/)

## Colophon

The site is built with mango, a static site generator, from plain markdown files. There
is no JavaScript and no tracking. The [RSS feed](/feed.xml) has the latest posts.
